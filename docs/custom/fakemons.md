# Fakemons - Custom Pokemon

This document tracks all custom Pokemon (fakemons) created for the Nono Edition ROM.

## Design Template

For each fakemon, document:
- **Name** - Pokemon name
- **Pokedex Number** - Which slot it occupies
- **Type** - Primary/Secondary type
- **Base Stats** - HP, Attack, Defense, Sp.Atk, Sp.Def, Speed
- **Abilities** - Primary/Hidden abilities
- **Evolution** - Evolution line (if any)
- **Design Notes** - Concept, inspiration, lore
- **Sprite Status** - Front/Back/Shiny sprite completion
- **Cry** - Sound effect status
- **Learnset** - Moves learned by level/TM
