# Changelog

All notable changes to the Nono Edition ROM will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [Unreleased]

### Added
- Development workflow with automated build-and-test scripts
- Custom documentation structure in `docs/custom/`
- Feature tracking system (planned/completed features)
- **Gain experience from catching Pokemon** - Like newer Pokemon games
- **Running shoes indoors** - Use running/biking inside buildings
- **Reusable TMs** - Infinite uses like HMs

### Changed
- **Pokemon Center healing speed** - 4-5x faster (all delays reduced)
- **Bag capacity** - Balls 12→13, Key Items 25→26, PC 50→52 (Items unchanged due to memory)
- **Text speed** - Fast=instant, Medium=1 frame (was 3), Slow=2 frames (was 5)
- **Shiny odds** - ~16x more common (1/512 instead of 1/8192)
- **Egg hatching speed** - 4x faster (eggs hatch in 1/4 the steps)

### Fixed
- Nothing yet

## [0.1.0] - 2025-12-30

### Added
- Initial project setup
- Fork from pret/pokecrystal on `nono-edition` branch
- CLAUDE.md AI assistant guide
