# Nono Edition - Custom Pokemon Crystal ROM

This directory contains documentation for the "Nono Edition" custom Pokemon Crystal ROM hack.

## Purpose

This ROM hack is a custom version of Pokemon Crystal created for my kids, featuring:
- Custom "fakemons" (original Pokemon designs)
- Custom village with family and friends' houses
- Selected features from pret wiki tutorials
- Quality-of-life improvements

## Documentation Structure

- **DEVELOPMENT.md** - Development workflow, build process, testing guide
- **planned-features.md** - Features planned but not yet implemented
- **completed-features.md** - Completed features with dates and commits
- **changelog.md** - Version history and release notes
- **fakemons.md** - Custom Pokemon designs and stats

## Getting Started

1. Read DEVELOPMENT.md for workflow setup
2. Check planned-features.md for what's coming next
3. Each feature should be developed in its own branch
4. Update documentation as you implement features

## Branch Strategy

- `master` - Official pret upstream (for pulling updates)
- `nono-edition` - Main development branch for custom ROM
- `feature/*` - Individual feature branches (merge to nono-edition when complete)
